# Data-works

Data engineering projects I build on my own data and on public data. Each folder is a
self-contained project with its own README, tests and CI.

| Project | What it does | Built with |
| --- | --- | --- |
| [tripforge](tripforge/) | Rough trip notes in; day-by-day itinerary, interactive map and costed PDF out | Python · DuckDB · Ollama · OpenStreetMap · Folium · ReportLab |

Same rules in every project: loads that are safe to re-run, typed data contracts, quality checks
before anything is published, tests in CI, LLM output validated before it is used.
